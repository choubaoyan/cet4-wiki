# CET-4 词林 · 四级词汇百科

一个纯静态的 CET-4 词汇百科页面：双击 `index.html` 就能用，不需要服务器、不需要联网、不需要账号。

## 怎么打开

- **直接双击** `index.html`（已验证 file:// 下正常，数据靠同目录 `data.js` 加载）
- 或者在本目录起一个静态服务：`python -m http.server 8765`，然后访问 <http://127.0.0.1:8765>
- 想放到网上：整个目录丢到 GitHub Pages / Vercel / 任意静态托管都能直接跑

## 功能

| 页面 | 路由 | 说明 |
|---|---|---|
| 首页 | `#/` | 今日一词、字母索引（26 组）、最近浏览、学习进度 |
| 字母列表 | `#/l/A` | 按首字母浏览该组全部词条 |
| 词条 | `#/w/abandon` | 美/英音标（点击朗读）、分条释义、形近词、上一个/下一个 |
| 生词本 | `#/book` | 词条页点「加入生词本」后汇总在这里 |
| 学习模式 | `#/study` | 翻卡记忆 + 看词选义（4 选 1），答对自动标记已掌握 |
| 关于 | `#/about` | 快捷键与数据说明 |

**搜索**：支持英文前缀/包含匹配，也支持**中文释义**搜索（输入「放弃」会命中 abandon / compromise / quit / resign / surrender）。

**快捷键**：`/` 聚焦搜索，`↑↓` 选结果，`Enter` 打开，`Esc` 关闭，学习页 `空格` 翻卡。

**数据**：2607 个 CET-4 核心词，含美/英音标与中文释义。形近词用「共同前缀 + 编辑距离 ≤ 2」本地推导，不调用任何外部接口。

**存储**：生词本、已掌握、最近浏览都写在浏览器 `localStorage`，换设备不同步（比赛演示够用）。
